# Arc Builder Playground

An educational onchain application built with [Arc Studio](https://studio.arc.io/), demonstrating how natural-language prompts, protocol skills, and smart contracts can be used to build an interactive blockchain application.

## Project Overview

Arc Builder Playground demonstrates two independent onchain development experiences:

### 1. Uniswap Swap Explorer

A consumer-friendly interface for exploring USDC and cirBTC swaps through Uniswap on Arc Mainnet.

Features:
- Uniswap integration research using the Arc Studio Uniswap skill.
- Pool and liquidity information.
- Swap quote exploration.
- Estimated output and fee information.
- Beginner-friendly transaction review interface.

**Demonstration limitation:** The workshop version is designed for research and read-only quote exploration. It does not execute real-money swaps.

### 2. Onchain Guestbook

A simple Solidity-based application deployed to Arc Testnet.

Features:
- Wallet connection.
- Publish public messages.
- Store messages onchain.
- Read previously published messages.
- Display sender addresses and timestamps.
- Transaction status and confirmation feedback.

The Guestbook is an educational demonstration and does not handle token transfers or payments.

## Network Separation

This project demonstrates two different environments:

| Module | Network | Purpose |
|---|---|---|
| Uniswap Swap Explorer | Arc Mainnet | Research and read-only quote demonstration |
| Onchain Guestbook | Arc Testnet | Smart contract deployment and interaction |

These modules are intentionally kept separate. The testnet Guestbook does not use the mainnet Uniswap pool.

## Getting Started

1. Open [Arc Studio](https://studio.arc.io/).
2. Create the Arc Builder Playground project.
3. Follow the six prompts in the workshop guide.
4. Select the Uniswap skill when instructed.
5. Select the Smart Contract skill when instructed.
6. Review and test the generated application.
7. Deploy the Guestbook contract to Arc Testnet after reviewing the generated code and tests.

## Important Notes

- This project is for educational and demonstration purposes.
- AI-generated code must be reviewed and tested.
- Never publish private keys, API secrets, or entity secrets.
- Guestbook messages are public and permanently recorded onchain.
- Do not enter personal or confidential information into the Guestbook.
- The Uniswap interface in this workshop does not execute real-money swaps.
- Testnet deployment is not a security audit or production approval.
- Any future mainnet integration requires independent code review, testing, and security validation.
